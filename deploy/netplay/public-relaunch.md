## Ranked and direct play

`InferenceEngine` batches multiple connections and keeps per-stream state.
The public runner owns one shared engine and one Dolphin per leased account.
Ranked currently prepares a separate engine with capacity one. Both current
launch configurations use HAL#647, display :90, Slippi port 51441, and the
OBS stream endpoint. They are not a concurrent deployment.

Concurrent operation needs a separate Slippi account for each match, separate
emulator ports/displays, one explicit stream owner, and qualification at the
combined capacity. Ranked would need to become a client of the shared engine
or run with a separately measured GPU budget. This rollout does not add that
mode. The old x_pilot scheduler is failed/stopped; its chat listener remains
active and no chat commands were sent.

### Read-rate estimate

For one continuously idle runner, the local measured costs imply 138,240
rows/day for claims (8 rows every five seconds) and 475,200 rows/day for
heartbeats (11 rows every two seconds): 613,440 rows/day combined. Each browser
tab open all day adds approximately 120,960 rows through capacity polling
(7 rows every five seconds). Game transitions, active job polling, startup,
and alarm work add traffic. These estimates are not a production usage audit.
