# Conditioned self-play evaluation

`self_play_policy.py` runs the same per-frame actor in Dolphin and MSL. Each
player supplies a KL coefficient, delay, replan interval, and identity at
u*=0.95. A decision at frame t first executes at t+delay+1. Both players
re-encode history through a second cache for each 128-frame block.
`--history-mode sliding` selects the sliding-context control. Evaluation
currently uses eager FP32 inference. Deployment latency needs separate tests.

```sh
PYTHONPATH="$HOME/src/melee-sim-light" xvfb-run -a uv run python -m scripts.eval_o65 \
  --checkpoint runs/actor.pt --anchors runs/proxy/final.pt \
  --output runs/evaluation/update-00000100 \
  --data-dir "$HOME/src/melee-sim-light/data" \
  --lambda-grid 0.01 0.1 1 10 100 --cadence-grid 8/4 10/2
```

Build the adapter with [the native instructions](../sim/NATIVE.md).
`--simulators dolphin` or `--simulators msl` selects a backend.
`--compare-events` compares MSL minus Dolphin in each matrix cell and requires
distinct actor behavior. Different identities or cadences can distinguish the
same checkpoint. At BC initialization, changing only lambda leaves behavior
unchanged. Changes confined to critic heads also leave the actor unchanged.

## Match data

`conditioned_matchups.py` loads fixed seeds and fresh-match starts, then runs
each seed/start with both port orientations. Starts specify stage and internal
character kinds, with four stocks and zero percent. Policy draws use a separate
counter for each logical player. Port orientation and simulator choice preserve
those draws. MSL readback passes through `native_controller_readback` before
feature construction; committed queues retain submitted factors.

Dolphin's Session API cannot inject game RNG or arbitrary starting states.
Reports retain its observed initial RNG. Simulator comparisons therefore
measure event statistics under the same policy draws and fresh starts.

Pass `--protocol path.json` to supply `hal.o65.protocol.v1`, with `selection`,
`held_out`, and `max_frames`. Each set contains `seeds` and `starts`; each start
contains `name`, `stage`, and `characters`. Selection and held-out sets must
use disjoint seeds and physical starts, including mirrored character pairs.
A held-out invocation consumes a claim file in the output's parent directory,
including if evaluation fails. Keep a shared results parent and run the full
final condition grid in that invocation.

The evaluator writes `protocol.json` before play and partial match files after
each match. It publishes `results.json` by atomic rename after the full schedule
succeeds. Failed emulator matches fail evaluation. Replay player labels include
checkpoint and condition hashes.

Intervals use paired seed/start units. Net stocks/min averages paired rates;
`net_stock_lcb` gives the one-sided 95% normal lower bound. Win rate scores
stockouts. Reports list timeout and frame-budget rates separately. Fewer than
two units gives null interval bounds. Event rates count active frames from
frame id 0, including death, ledge-grab, and tech onsets. The default budget
includes 123 countdown frames and the timeout frame at 28,800.

## Training calls

At update boundaries, the trainer passes a manifest to `PeriodicEvaluator`
from `periodic_self_play.py`. It retains the evaluator for the run, calls
`poll()` to collect results or raise a child failure, then calls `submit()` at
the configured interval. A busy evaluator defers another submission. At normal
shutdown, `finish()` waits and checks the child's result; `close()` releases
its process and log.

`self_play_checkpoint.py` checks the manifest version, actor hash, evaluated
update, and input records. Training restore also compares exported actor tensors
with the training state. The `hal.o65.training.v2` manifest references the
complete training state, native snapshots, and `hal.o65.evaluation.v1` actor.
The actor file includes architecture, conditioning ranges, tensors, feature
statistics, and source/input records.

The loader also accepts the exact O63 bootstrap30 checkpoint with SHA-256
`65e7e43e5cbb18a365a005922ec1cfd026ad807c045eae13b331f487b4ec82e6` and
its recorded feature-statistics hash. Other schemas require an explicit export.
Periodic jobs use the selection set and run locally. Use an existing display
or Xvfb for Dolphin, and a separate device if concurrent evaluation exceeds
available GPU memory.
