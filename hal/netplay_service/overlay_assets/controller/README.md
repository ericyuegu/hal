Controller paths adapted from SlippiLab `src/components/panels/Inputs.tsx`
(https://github.com/frankborden/slippilab). MIT license: see LICENSE.
The body omits the cable; all controller parts, including shoulders, are retained.
The full body and shoulders fit proportionally inside the SVG viewBox.
The palette matches the HAL stream. PNG layers are generated from controller.svg
by scripts/prepare_overlay_assets.py. Runtime composition needs only Pillow.
Character PNGs are exact copies of web/netplay/public/characters.
